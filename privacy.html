English Lesson Studio

Privacy policy

Updated 14 October 2026

English Lesson Studio is a personal local tool operated by Sebastiaan van Wyk for the Sebastiaan Teaches YouTube channel.

Information the tool uses

The tool uses Google OAuth authorization tokens, the connected YouTube channel's ID and name, playlist IDs, video metadata, caption records and upload status. It also stores lesson scripts, images, narration, subtitles and finished videos on the operator's Mac.

Purpose of access

YouTube access is used to upload lesson videos, add English captions and thumbnails, create and manage level playlists, check processing results, and change visibility when the operator chooses to publish. Google provides a permission scope that also allows other video-management actions; the workflow uses that scope for the features described here.

Storage and protection

Authorization tokens and client credentials are stored locally in files with restricted permissions. Lesson records are stored in a local database. Credentials are not included in this public website or its source. Backups made by the operator may also contain this local data and must be protected.

Data sharing

Videos, captions, thumbnails and related metadata are sent to YouTube when uploading. Google receives authorization and API requests. If the optional Pexels integration is enabled, image-search terms are sent to Pexels and selected images are downloaded. Lesson drafting and voice synthesis use local models rather than a paid external AI service.

The operator does not sell Google API data or use it for advertising or model training. Google API information is used for the features described here, consistent with the Google API Services User Data Policy and its Limited Use requirements.

Visibility

Videos initially upload privately. Public mode is an operator-controlled setting that makes completed videos and their corresponding playlists public. YouTube's own privacy rules apply to content stored on YouTube.

Retention and deletion

Local lesson files, upload records and credentials remain until the operator deletes them. Access can be revoked through Google Account permissions. Removing local files does not remove videos already uploaded to YouTube; those can be managed separately in YouTube Studio.

This website

This informational website has no sign-in form, advertising or analytics added by the operator. Its hosting provider may process ordinary request information under its own privacy policy.
